# Mr Cohen Simulator

Mr Cohen Simulator is a simulation of Mr Cohen's classroom
There are **2** main aspects of the simulation:
- The classroom
- Mr Cohen's Computer

Many modifers/settings can be changed to spice up or change the outcome of the simulation:
- Student IQ
- Starting computer type
- Chaos level
- Chance of computer breaking
- Number of days
- Customer support speed
